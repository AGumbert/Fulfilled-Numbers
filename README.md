# Fulfilling-Numbers
Explores the novel concept of a "Fulfilling" number, associated with the aliquot function from number theory (s(n)). A "fulfilling" number is equal to its own "fulfillment" function f(n), where f(n) = s(n) plus the sum of f(n) recursively applied to each proper divisor of n. 4, 10, and 195 are fulfilling numbers.
